# Northflank Provider

Manages [Northflank](https://northflank.com) resources as code, through the
[Northflank API](https://northflank.com/docs/v1/api/introduction).

## Example Usage

```terraform
terraform {
  required_providers {
    northflank = {
      source  = "srs/northflank"
      version = "0.1.0"
    }
  }
}

# The token may also be supplied with the NORTHFLANK_API_TOKEN environment
# variable, and the endpoint with NORTHFLANK_ENDPOINT.
provider "northflank" {
  token = var.northflank_token
}

variable "northflank_token" {
  type        = string
  sensitive   = true
  description = "Northflank API token, created in the dashboard under team settings, API, Tokens."
}
```

## Authentication

The provider authenticates with a Northflank API token. Tokens are created in
the Northflank dashboard under team settings, API, Tokens, from an API role
that decides what the token may do. A token belongs to a team, and every
request acts on that team.

Prefer the `NORTHFLANK_API_TOKEN` environment variable so the token stays out
of configuration files:

```shell
export NORTHFLANK_API_TOKEN="..."
```

### Optional

- `endpoint` (String) Base URL of the Northflank API, without the `/v1` suffix. Defaults to `https://api.northflank.com`, or the `NORTHFLANK_ENDPOINT` environment variable when set.
- `token` (String, Sensitive) API token used to authenticate against the Northflank API. Tokens belong to a team and carry the permissions of the API role they were created from. May also be set with the `NORTHFLANK_API_TOKEN` environment variable.
